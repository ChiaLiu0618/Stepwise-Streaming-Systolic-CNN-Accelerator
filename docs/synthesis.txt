Constraints and limits
----------------------
Library: NangateOpenCellLibrary_typical.lib, Nangate45, 1.1 V, 25 C.
ABC mapping: 2500 ps target, BUF_X1 input driver, 5 fF output load;
default constrained mapping includes buffering, upsizing, and downsizing.
STA: 2.5 ns ideal clock, 0.05 ns uncertainty, max input/output delays 0.2 ns,
min input/output delays 0 ns, input transition 0.05 ns, output load 5 fF.
The asynchronous reset input is false-pathed; reset recovery/removal is
not characterized by this run. No placement, CTS, routing, wire parasitics,
physical design checks, switching-activity analysis, or power estimation.

Area is the sum of mapped Liberty cell areas, not core/die area.
The weight regfiles are implemented as flip-flops and selection/control
logic rather than dedicated register-file or SRAM macros. A compatible
macro could reduce storage area, but no reduction has been measured.
The final area must include macro interfaces and physical implementation
overhead. Macro integration must address combinational read timing, byte
write enables, and asynchronous reset semantics; a percentage reduction
cannot be assumed from these synthesis results alone.
The estimated clock limit is not measured silicon performance. The 400 MHz
target is met only by this pre-layout timing model and its stated constraints.

An initial mapping without ABC drive/load constraints exposed extreme
mode-control fanout. The reported final mapping uses constrained ABC
buffering and sizing; the initial unbuffered result is not the final result.
Yosys final check -assert reports no structural problems. Intermediate
warnings about conflicting loop-index drivers refer to discarded procedural
loop variables i/j, not retained datapath registers. Register arrays are
intentionally lowered to standard-cell storage.

Reproduction
------------
./synth.sh

Default dependency root: ~/Desktop/Mixed Precision Conference
Override MIXED_PRECISION_ROOT, or set LIBERTY_PATH and STA_BIN directly.
sv2v, yosys, iverilog, vvp, and Python 3 are required.
CLOCK_PERIOD_NS overrides the mapping/STA target; changing it requires remapping.
./synth.sh --reuse-mapping reruns analysis and the gate test only when the
stored source/library/tool/flow hashes still match. It does not accept a
stale mapping for different RTL or constraints.

The runner records provenance in build/synthesis/mapping_inputs.json and
results in build/synthesis/summary.json. It also emits area.txt, timing.log,
gate.log, Yosys logs, and generated netlists under build/synthesis/.
Only the runner and this reviewed summary belong in Git; copied libraries,
cell models, netlists, binaries, and generated reports remain ignored.
